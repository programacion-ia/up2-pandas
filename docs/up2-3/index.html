1Seleccionar con loc e iloc

  1. 1loc: un valor por etiqueta y columnaloc[etiqueta, "columna"] elige una celda por sus nombres.›
  2. 2loc con un tramo: el final sí entraloc[0:2, ...] da las etiquetas 0, 1 y 2.›
  3. 3loc[:, columnas]: todas las filasLos dos puntos solos significan todas las filas.›
  4. 4iloc: un valor por posicióniloc[fila, columna] cuenta posiciones desde 0, como en NumPy.›
  5. 5iloc con un tramo: el final no entrailoc[0:2] da las posiciones 0 y 1.›
  6. 6iloc[-1]: desde el finalLas posiciones negativas cuentan desde el final.›
  7. 7set_index: una columna como etiquetasLas etiquetas pasan a tener significado: el id del anuncio.›
